# Форматы заданий v9

Исправлены обе десктопные темы принятого постера. В правой колонке переставлены фиолетовый и лаймовый терминалы; шнуры перерисованы в цвет своих пар. Фиолетовый соединяет верхние терминалы, мятный средний левый с нижним правым, лаймовый нижний левый со средним правым. Все три соединения непрерывны и взаимно однозначны. Сохранены четыре радиокруга с одним выбранным и пять квадратов с двумя отметками.

Созданы две отдельные мобильные композиции в том же бумажном рельефе. Первая мобильная генерация занимала графикой места подписей; сохранена как artwork-mobile-dark-initial.png. Повторная генерация раздвинула сцены и освободила текстовые полосы. Светлая мобильная тема получена из этой исправленной сцены. Это одна художественная сцена на каждый баннер; отдельные изображения объектов поверх неё не накладывались.

Подписи воспроизводятся HTML-макетами с локальным Unbounded450 и Arial. Десктоп 1600 × 1200, мобильная композиция 1000 × 1800. README использует четыре оптимизированных JPG: мобильные source стоят первыми и действуют до 600 px, десктопная ширина задана 960 px. Размеры JPG от 411 897 до 442 948 байт. Первичные PNG, промпты, точная типографика и хеши сохранены рядом. Растровая художественная сцена не содержит редактируемых слоёв; для её замены повторяется ImageGen с сохранённым промптом и указанным референсом, затем экспортируется соответствующий HTML-макет через Playwright MCP.
