# Финальный бриф

Иллюстрация трёх способов ответа: один правильный вариант, несколько правильных вариантов и сопоставление пар. В банке 72 одиночных задания, 72 мультивыбора и 36 сопоставлений. Финальный мобильный вариант используется сейчас; десктопная пара публиковалась раньше и сохранена в архиве.
