# Архив финальных креативов README

Архив хранит материалы только для финальных изображений, которые используются сейчас или были опубликованы в сохранённой версии README `4c3b47b`. Исходники текущих изображений остаются в `assets/readme/`, повторных копий здесь нет.

Для каждого финала оставлены короткий бриф, относящиеся к нему промпты и компактный манифест с путями публикации и SHA-256. Промпты для отклонённых вариантов, черновых состояний и заменённых изображений удалены вместе с сырыми слоями, превью, проверками и макетами.
