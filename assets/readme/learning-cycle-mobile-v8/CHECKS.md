# Мобильный учебный цикл v8

Две вертикальные композиции 1000 × 1800 созданы встроенным Image Generation по десктопному референсу v7. Все предметы перерисованы внутри общей сцены. Исходные PNG, промпты и хеши сохранены; художественный слой плоский, типографика редактируется в двух HTML-макетах.

Заголовки используют локальный Unbounded с весом 450, основной текст Arial. Оба WOFF2 загружены через Playwright MCP. Переполнения девяти текстовых контейнеров нет. JPG экспортированы с качеством 95 и без цветовой субдискретизации, WebP сохранены дополнительно.

Контраст измерен под непрозрачными пикселями всех двадцати фрагментов текста в каждой теме. Для PNG минимумы 5,978:1 и 5,488:1, для итоговых JPG 5,475:1 и 4,869:1. Первоначальное пересечение второй строки заголовка со светлой карточкой исправлено уменьшением заголовка до 54 px и увеличением свободного места. Повторные фокусные проверки прошли.

Галерея просмотрена на ширине 375 px и в парном виде. В локальной интеграции README на 375 px выбирает мобильный цикл в нужной теме; на 960 px остаются прежние десктопные версии v7. Все четыре сочетания загрузились без переполнения страницы. Целевой GitHub и нативное приложение GitHub в этой части не проверялись.

Route QUICK. Прежние независимые волны initial=1, recheck=1/max1 сохранены. Новых независимых reviews и плановых gates нет. Hero, прежние постеры, презентации и код приложения не изменялись. Визуальная приёмка остаётся за пользователем. Сводка десяти критериев находится в docs/readme/UPDATE_2026-10-11.md.
