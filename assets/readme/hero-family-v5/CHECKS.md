# Production notes: hero family v5

Статус: **четыре hero-варианта созданы и подключены в README; production-проверки root пройдены**.

Этот файл фиксирует проверки конкретного семейства hero v5. Независимый review не запускался; прежние счётчики initial=1 и recheck=1/max1 сохранены. Принятие художественного результата остаётся за пользователем.

## Scope композиции

Семейство состоит из четырёх отдельных raster-сцен:

| Тема | Desktop | Mobile |
| --- | --- | --- |
| Dark | тёмный desktop с исправленным ритмом и равными просветами между тремя формами | заново скомпонованная мобильная dark-сцена |
| Light | светлый desktop в проектной светлой палитре | заново скомпонованная мобильная light-сцена |

Во всех вариантах три тестовые формы остаются различимыми, имеют одинаковый видимый вес, общую плоскость и равные просветы. Бирюзовая форма не должна исчезать за соседними объектами. Принятые решения v4 сохраняются: компактный пятилистный знак, увеличенное название Unbounded и воздушный ритм текста с pills ниже.

Для dark используются фон `#24212d`, текст `#f2edf8`, акценты `#d3e38c`, `#93d7d0`, `#c5a8f2` и непрозрачные поверхности pills `#343c27`, `#273f40`, `#3b304d`. Для light используются фон `#f0edf4`, текст `#25212b`, label `#6841ab`, а также непрозрачные пары ink/fill: lime `#465c16`/`#e6efa9`, teal `#005b64`/`#d6efeb`, lilac `#6841ab`/`#e9dcfb`.

Заголовки и название используют локальный Unbounded, основной текст и подписи pills – системный Arial, как на сайте. Точный copy во всех вариантах: `Тренажёр компетенций ИИ`, `Основы работы с ИИ`, `Практика перед экзаменом.`, `Разбор после каждого ответа.`, `180 вопросов`, `3 уровня`, `6 доменов`.

Редактируемыми остаются типографика и pills в HTML. Сама иллюстрация является плоским raster; для замены используются сохранённые промпты и ImageGen. Альтернативный уменьшенный вариант исключён из доставки. Известные исправления и focused checks записаны в `manifest.json`; они не расходуют независимый review budget.
