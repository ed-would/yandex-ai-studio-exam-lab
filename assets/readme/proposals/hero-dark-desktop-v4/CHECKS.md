# Проверки кандидата hero v4

Статус: **production-проверки root пройдены; ожидает принятия дизайна пользователем**.

Записка относится к одному кандидату `hero-dark-desktop-v4`: тёмный desktop hero для оценки пользователем. README не получает новую ссылку до принятия кандидата.

## Зафиксированная композиция

Три тестовые формы должны быть частью одной ImageGen-сцены и находиться на одном переднем плане с одинаковым визуальным весом, высотой и дистанцией. Лаймовая, бирюзовая и сиреневая формы остаются раздельно узнаваемыми; бирюзовая форма не скрывается за соседними объектами.

Слева выстроен свободный вертикальный ритм: компактный пятилистный знак около 48 px в финальном экспорте (целевой размер brief – около 54 px) и увеличенное название тренажёра Unbounded около 32 px в верхней части, затем заголовок, разреженный основной текст и три непрозрачных pills в нижней части. Pills используют тёмные брендовые поверхности: лаймовую `#343c27`, бирюзовую `#273f40` и сиреневую `#3b304d`. Точный заголовок набран локальным Unbounded, основной текст и подписи pills – системным Arial, как на сайте.
