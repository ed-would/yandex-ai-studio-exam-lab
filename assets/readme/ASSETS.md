Все изображения, нужные README, находятся в репозитории. Для их отображения не нужен внешний сервис. Факты, показанные в баннерах, повторены обычным текстом и таблицами в README.

Художественные композиции созданы встроенным Image Generation. Объёмные ленты используют лаймовую, бирюзовую и лиловую палитры из `DESIGN.md`. Это растровая графика; баннеры не содержат встроенной SVG-сцены. Статические SVG-иконки в заголовках README относятся к отдельному набору Lucide.

Референсы трёх тестов находятся в `public/images/artwork/`: `level-1-foundations-1254-optimized.webp`, `level-2-application-1254-optimized.webp` и `level-3-expert-1254-optimized.webp`. В новом hero формы перерисованы внутри общей ImageGen-сцены со светом, контактными тенями и отражениями. Пятилистный знак тренажёра из `public/images/brand/trainer-abstract-256-optimized.webp` отдельно перерисован в шапке. Формы трёх уровней имеют сопоставимый визуальный вес и отдельные просветы. Мобильная сцена скомпонована заново по вертикали.

В макетах hero используется один растровый слой со всей художественной сценой. HTML добавляет точную типографику и три непрозрачных цветовых бейджа; браузер отрисовывает готовый PNG. PNG кодируется в WebP без изменения композиции. Десктопный банк v6 также использует одну цельную ImageGen-сцену. Новый учебный цикл v7 использует другой предметный сюжет с четырьмя этапами внутри одной генеративной сцены.

README выбирает hero через `<picture>`: сначала мобильные варианты при ширине до 600 px, затем desktop, с условиями `prefers-color-scheme`. Fallback `<img>` содержит светлый мобильный hero для клиентов без поддержки `<picture>`. Четыре сочетания проверены локально через Playwright MCP. GitHub web документирует `<picture>` и выбор темы, но опубликованная страница и нативное приложение GitHub в этой работе не проверялись. Источники и ограничения записаны в `hero-family-v5/github-media.md`.

## Шрифты

Заголовки набраны в **Unbounded**, основной текст в **Arial**, как на сайте. Макеты загружают оба локальных файла `public/fonts/unbounded-cyrillic-variable.woff2` и `unbounded-latin-variable.woff2`; второй нужен также для цифр и знаков. Unbounded распространяется по SIL Open Font License; уведомление находится в `public/fonts/Unbounded-OFL.txt`. Arial использует браузерную системную установку и не включается отдельным файлом в комплект графики.

В готовых PNG/WebP шрифт уже отрисован, поэтому установка Unbounded читателю README не нужна. Редактируемая презентация PPTX содержит названия семейств, но не встраивает шрифты: для точного отображения её заголовков в PowerPoint потребуется установленный Unbounded. PDF и превью презентации отрисованы браузером с локальными WOFF2.

## Настоящие экраны

В `screenshots/` сохранены PNG и более компактные WebP главной, первого задания в двух темах, материалов и результата. Это снимки работающего приложения через Playwright MCP. Главная и задание сняты в обычном режиме; для результата и материалов использован `dev:results`. Результат 48 из 60 является явно обозначенным демонстрационным сценарием, а не измерением качества подготовки или официальной оценки.

## Исходники и замена

В `hero-mobile-v6/` сохранены исправленные мобильные хиро: название выровнено по видимому центру знака, цвет названия совпадает с принятой десктопной версией. В тёмной сцене Image Generation приглушил свет за названием. Точная типографика и бейджи остаются в HTML, проверки и происхождение записаны рядом. Принятые десктопные хиро v5 не изменялись.

В `hero-family-v5/` сохранены промпты, исходные PNG генерации, четыре HTML-макета, итоговые PNG/WebP и проверки нового hero. Его `manifest.json` фиксирует источники, размеры, объём и SHA-256. В `source/` и прежнем `manifest.json` остаются исходники остальных баннеров и предыдущей обложки. Первые варианты и корректировки сохраняют происхождение работы.

Чтобы обновить подпись, измените текст в соответствующем `*.layout.html`. Для замены сцены hero выполните Image Generation с сохранёнными промптами и референсами, затем обновите единственный путь к artwork в макете. Промпт описывает генерацию, а HTML хранит редактируемую типографику и бейджи; сам PNG является плоским растровым изображением.

Откройте макет через сервер `npm run dev`, дождитесь загрузки шрифтов и изображений и снимите элемент `#capture` через `/pw`. Новый desktop hero имеет размер 1600 × 700, mobile hero 900 × 1300. Новый десктопный банк имеет размер 1600 × 900, кандидат учебного цикла 1600 × 1000. Прежний цикл имеет размер 1774 × 887; узкие исходные макеты: банк 900 × 1900, цикл 900 × 1840. При замене проверьте заголовки, числа, границы объектов и читаемость при фактической ширине README. Сохраните PNG и обновите соответствующий WebP и запись в манифесте.

Презентация и порядок её пересборки находятся в `docs/readme/`: `presentation.mjs`, `presentation-preview.html` и `presentation-notes.md`. Итоговые файлы: PDF, редактируемый PPTX, общий лист и восемь полноразмерных превью.

## Права и происхождение

Проектные изображения переиспользованы из `public/`; новая графика создана для этого репозитория. К ним применяется лицензия проекта MIT в пределах прав автора. Названия Яндекса и его сервисов остаются обозначениями соответствующего правообладателя и не означают одобрения проекта.

Иконки экспортированы из установленного Lucide 1.8.0; исходное уведомление ISC сохранено в `icons/LICENSE`. Их назначение соответствует разделу, обводка использует экспертный фиолетовый `#6841AB`. Светлая подложка обеспечивает читаемость и на тёмной странице.

Предыдущая полная проверка README записана в `docs/readme/REPORT.md`. Актуальные проверки четырёх hero-вариантов находятся в `hero-family-v5/CHECKS.md`.

Мобильные исправления проверены отдельно в `hero-mobile-v6/CHECKS.md`.

Десктопная инфографика банка v6 была принята пользователем. По новому запросу её место в README занимает кандидат о форматах заданий. Все прежние файлы сохранены без изменений в `bank-map-v6/` для истории и сравнения.

Десктопный учебный цикл находится в `learning-cycle-v7/`, размер 1600 × 1000. Его отдельные мобильные композиции находятся в `learning-cycle-mobile-v8/`, размер 1000 × 1800. Они соединены в одном picture по теме и ширине экрана. Четыре предметных сцены перерисованы внутри общей генерации; точные подписи набраны в Unbounded и Arial.

Актуальный второй постер находится в `question-formats-v9/`: desktop 1600 × 1200 и mobile 1000 × 1800 в двух темах. Бумажный рельеф и физические элементы выбора показывают три формата ответа. У каждой пары совпадают цвета обоих терминалов и шнура. Это предметная иллюстрация, а не снимок интерфейса. Цвета не связывают форматы с уровнями: все форматы встречаются во всех уровнях. README использует JPG и выбирает отдельную мобильную композицию при ширине до 600 px; ширина десктопного изображения задана 960 px. Версия v8 сохранена без изменений. Галерея, исходники и проверки находятся рядом в каталоге v9.

Для обеих новых композиций сохранены первичные PNG Image Generation, промпты, редактируемая типографика HTML, PNG-экспорты, оптимизированные JPG для README и дополнительные WebP. JPG кодируются с качеством 95 и без цветовой субдискретизации. Проверки загрузки шрифтов, границ подписей, контраста и размеры файлов находятся рядом с каждым новым набором. Принятые hero и прежний банк не перекодировались.
