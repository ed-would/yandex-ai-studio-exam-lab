# Кандидаты инфографики банка v6

Два десктопных варианта приняты пользователем и подключены в README. Размер каждого 1600 × 900. Выбор темы осуществляется через picture; отсутствующий старый мобильный источник удалён, на узком экране масштабируются десктопные варианты.

Сцены созданы встроенным Image Generation. Проектные формы перерисованы один раз каждая внутри общего освещения, пола, теней и отражений. Три формы сохраняют отдельные силуэты и сопоставимый визуальный вес. Знак тренажёра не повторяется. Оригинальные проектные картинки не наложены поверх сцен. Промпты, референсы, первичные PNG и отклонённая промежуточная композиция записаны в `generation-provenance.json`.

Текст и цветовые бейджи редактируются в двух HTML-макетах. Заголовки и формула используют локальный Unbounded с весом 450, подписи используют Arial. Цвета соответствуют DESIGN.md: лайм для базового, бирюза для продвинутого, сирень для экспертного. Инфографика показывает 180 авторских вопросов, три теста по 60, шесть доменов по десять вопросов на каждом уровне. Эти факты повторены в README обычным текстом и таблицами.

Через Playwright MCP подтверждены загрузка обоих локальных шрифтов и artwork, отсутствие переполнения контейнеров и экспорт 1600 × 900. Полные PNG и превью шириной 960 px просмотрены. Все 24 текстовых фрагмента проверены по фактическому фону: минимальный контраст 5,98:1 в тёмной теме и 5,09:1 в светлой.

При первой проверке подпись «на каждом уровне» попадала на световой блик с контрастом 2,80:1. Root объединил подпись и формулу в одну непрозрачную лиловую подложку и увеличил нижний отступ. Повторная проверка исправленного фрагмента прошла. Первоначальный снимок HTML хранится как `source-initial.sha256`, актуальные хеши как `source.sha256`.

Route QUICK, дополнительного независимого review нет. Сохранены прежние initial=1, recheck=1/max1. Мобильные варианты инфографики, другие баннеры, презентации и приложение в этот этап не входят.

Финальная общая проверка `npm run check` прошла: lint, форматирование, контракт банка, тесты и сборка. `git diff --check` также прошёл.
