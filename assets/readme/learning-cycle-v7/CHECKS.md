# Учебный цикл v7

Две новые десктопные композиции подготовлены для просмотра. Размер 1600 × 1000. Новый сюжет состоит из четырёх сцен: выбор на карточке, проверка с замком, раскрытый разбор с лупой и повторение на новом наборе карточек. Направление задают встроенные в сцену стрелки. Тестовые скульптуры, логотип, числа банка и волновой фон предыдущих баннеров не повторяются.

Обе сцены целиком созданы встроенным Image Generation. Типографика набрана в локальном Unbounded с весом 450; основной текст в Arial. Нумерация и подписи используют сиреневую роль интерфейса, в новых предметах сохранены мятные и лаймовые блики. HTML содержит один artwork и редактируемые подписи; исходные проектные картинки не накладываются поверх сцены. Художественная часть остаётся плоским PNG, её замена требует новой генерации по сохранённым промптам.

Содержание сверено с текущими путями приложения; ссылки на доказательства находятся в `facts.json`. Черновик можно менять до фиксации. Проверка сохраняет ответ и показывает баллы с разбором. Объяснения рассматривают варианты или пары, дают памятку и источники. После завершения теста ошибки и непроверенные задания переходят в новую отдельную попытку; исходные ответы остаются в истории. Существующий таймер может зафиксировать пустой ответ, поэтому подпись не обещает бесконечного времени на изменение черновика.

Playwright MCP подтвердил загрузку шрифтов и artwork, отсутствие переполнений пяти текстовых контейнеров и корректный размер. Оба готовых баннера просмотрены на ширине 960 px. Все 38 фрагментов текста проверены по фактическому фону: минимальный контраст 5,98:1 в тёмной теме и 5,49:1 в светлой. Ошибок в консоли итоговой страницы нет.

В первом варианте стрелки пересекали будущие зоны подписей; Image Generation перенёс два соединения вверх и вниз. Первоначальные сцены сохранены отдельно. Слишком длинная первая строка подписи повтора разбита на три строки без уменьшения шрифта. Фокусные проверки после этих исправлений прошли; независимого review не было.

Route QUICK. Прежние review initial=1, recheck=1/max1 сохранены; новых review и плановых gates нет. Мобильные варианты этой инфографики, презентации, другие новые баннеры и код приложения исключены из этапа. Принятые пользователем десктопные варианты банка v6 подключены в README, их изображения и принятый hero не изменялись. Учебный цикл v7 подключён в локальном README для просмотра; его визуальное принятие остаётся за пользователем. Прежние корневые файлы банка и цикла отсутствуют, поэтому их несуществующие мобильные источники удалены из picture. На узком экране пока масштабируются десктопные версии.

Общая проверка `npm run check` прошла: lint, форматирование, контракт банка, тесты и сборка. После замены отсутствующих путей оба picture отдельно проверены в двух темах на ширинах 375 и 960 px: все изображения загружены, переполнения нет.
