# Новый второй постер v8

Кандидат показывает другую информацию: три способа ответа и распределение форматов 72 / 72 / 36. Числа сверены напрямую с шестью JSON-файлами банка; правила с questions.js и exam.js. Hero содержит общие числа и формы уровней, учебный цикл показывает последовательность работы. Новая композиция показывает механики ответа и не повторяет их сюжеты.

Две сцены 1600 × 1200 созданы встроенным Image Generation. В одной бумажной композиции находятся четыре радиокруга с одним выбранным, пять квадратов с двумя отметками и три соединения между двумя колонками. Это условная предметная иллюстрация, не снимок интерфейса и не ключ конкретного задания. Форматы не связываются с уровнями или цветами тестов. Старый банк v6 остаётся в своём каталоге без изменений.

Точные подписи набраны локальным Unbounded450 и Arial. Playwright MCP подтвердил загрузку обоих WOFF2, сцены и отсутствие переполнений. Минимальный контраст PNG 5,978:1 в тёмной теме и 4,834:1 в светлой; у финальных JPG 5,464:1 и 4,829:1. В светлой теме заголовки форматов переведены в нейтральный цвет текста: первоначальный фиолетовый заголовок попадал на тень бумаги с контрастом 3,824:1. Бейджи и подзаголовок сохранили экспертный фиолетовый.

Галерея обоих JPG проверена при ширине изображения 960 px. README подключает их через picture в разделе трёх форматов. На 375 px картинка масштабируется, отдельная мобильная версия нового постера не создавалась: пользователь запросил сначала две десктопные темы для просмотра. Целевой GitHub не проверялся. Экспорт браузера завершился через предписанный Playwright MCP; после зависания прежней вкладки использована новая вкладка и штатное местоположение снимков.

Route QUICK. Прежние независимые волны initial=1, recheck=1/max1 сохранены, новых reviews и плановых gates нет. Не изменялись hero, прежний банк, презентации, приложение, зависимости или runtime-токены. Кандидат подключён локально для просмотра; окончательная художественная приёмка остаётся за пользователем. Сводка десяти критериев находится в docs/readme/UPDATE_2026-10-11.md.
