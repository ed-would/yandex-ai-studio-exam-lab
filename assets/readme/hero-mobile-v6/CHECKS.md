# Исправление мобильных хиро v6

Две мобильные версии подключены в README. Десктопные хиро v5 сохранены побайтно.

Название набрано локальным Unbounded, вес 450. Его цвет: `#c5a8f2` в тёмной теме и `#6841ab` в светлой, как на принятых десктопных хиро. Основной текст и бейджи используют Arial. Иллюстрация остаётся одной цельной сценой, знак и формы перерисованы внутри неё. Встроенный Image Generation приглушил засветку верхней части тёмной сцены. Светлая сцена переиспользована без изменения.

Через Playwright MCP проверены загрузка шрифтов и artwork, отсутствие переполнения, итоговый размер 900 × 1300, отображение на ширине 375 и 320 px. Видимые центры знака и букв отличаются на 0,5 пикселя в полном экспорте, то есть на 0,21 пикселя при ширине 375. Измерение сохранено в `pixel-proof.json`; минимальный контраст названия 6,86:1 для тёмной темы и 5,45:1 для светлой. Все проверенные фрагменты имеют контраст не ниже 4,5:1.

Первый picture README проверен в обеих темах на ширинах 375, 600, 601 и 960 px; ожидаемый файл выбран и загружен, переполнения нет. Сведения о поддержке GitHub и границах проверки сохраняются в `../hero-family-v5/github-media.md`. Опубликованный README и нативное приложение GitHub не проверялись.

HTML хранит редактируемые буквы и бейджи. Artwork является плоским PNG: для изменения иллюстрации используется сохранённый промпт и Image Generation, после чего снимается `#capture` через `/pw` и кодируется WebP. Light artwork и исходный промпт взяты из v5. Источники, размеры и SHA-256 записаны в `manifest.json`.

Route QUICK, новых независимых review нет. Прежний счётчик initial=1, recheck=1/max1 сохранён. Другие баннеры этой версии, кроме отдельно запрошенного кандидата bank-map v6, презентации и код приложения не изменяются.

Финальная общая проверка `npm run check` прошла: lint, форматирование, контракт банка, тесты и сборка. `git diff --check` также прошёл.
