# Мобильный и планшетный аудит

Дата: 11 октября 2026. Продукт: веб-тренажёр компетенций ИИ, Preact/htm/Vite.

## Границы и критерии

Проверка через Playwright MCP (/pw): главная, три уровня, 180 вопросов, radio/checkbox/match, черновик/проверенный ответ, верно/ошибка/пропуск, закладки, таймер, карта, результаты, практика ошибок, история, шесть доменов материалов, поиск, фильтры, диалоги, импорт и экспорт. Ширины: 320/390/768/1024px, обе темы. На каждой проверяемой странице нет горизонтального переполнения; controls доступны с клавиатуры, сенсорные targets от 44px; длинный текст не перекрывает элементы.

Маршрут STANDARD: обычное исправление responsive UI, без архитектурной перестройки. Root владеет всеми изменениями и браузером. Начальный snapshot: be769d895da88aeb7dc68474ae1cdfc8891ec16b. Read-only explorer завершил карту. Один независимый reviewer, бюджет одного review-recheck; plan gate не нужен. Исключены существовавшие untracked docs/readme и docs/design-lab/artwork/project-geometry-five. Команда приёмки: `npm run check`.

## Найдено и исправлено

| Проблема | Причина | Решение |

## Журнал проверки

- Начальная диагностика: вопрос на 390px – 6 строк, высота 201.56px. После изменения тот же вопрос – 3 строки, около 82px.
- Все 180 заданий: четыре ширины, 648 option selections и 648 значений match selects; геометрических дефектов не найдено. Три полные попытки завершены, для каждой доступны все 60 разборов. Длинные кейсы выявили отдельную проблему типографического веса: добавлен спокойный размер 18px/1.4 для prompt длиннее 180 символов.
- Первая попытка браузерного обхода остановилась на намеренно неполном сопоставлении: disabled «Проверить» работает. Обход исправлен: неверная, но полная перестановка пар; уровень начат заново. Это ошибка сценария проверки, не дефект приложения.
- Initial reviewer: CHANGES_REQUIRED. Найдены поздний override заголовка Прогресса и слишком низкий sticky offset таймера. Оба исправлены одной партией вместе с root finding о длинных кейсах.
- Единственный review-recheck подтвердил эти исправления и выявил обрезанную подпись режима истории. Root исправил её; focused proof на 320/390/570/571/768/820/821/1024px подтвердил, что текст помещается. Повторный независимый обзор не запускался: initial reviews – 1, review-rechecks – 1/1.
- После проверки coarse pointer найден скрытый tablet sidebar. Root исправил границу и проверил 820/821/900/901/1024/1100/1101px. Переход на вопрос 10 через карту работает; мобильный accordion остаётся доступен.

Вспомогательные браузерные сценарии исправлялись при обнаружении ошибочных предположений: незавершённую практику необходимо подтверждать в диалоге перезапуска; после commit нужно дождаться состояния; у feedback и disconnect используются реальные selectors. Эти остановки сценариев не записаны как дефекты приложения. Исчезновение tablet sidebar, напротив, воспроизведено и исправлено в продукте.

## Приёмка и пределы проверки

Root acceptance: ACCEPTED. Открытых воспроизводимых дефектов в перечисленных сценариях не осталось. Итоговый `npm run check` после последней CSS-правки завершён с exit 0: oxlint, stylelint, форматирование, валидация банка, 160 тестов (160 pass / 0 fail), Vite build. `git diff --check` также проходит. Независимый бюджет использован: initial review 1, review-recheck 1/1; оставшиеся известные замечания закрыты root исправлениями и focused proof.

Проверка выполнена в Chromium через Playwright MCP: responsive размеры, реальное взаимодействие с controls и отдельные сенсорные contexts. Реальные Safari/iPhone/iPad, VoiceOver и системное увеличение текста на Apple-устройствах не проверялись. Reduced motion использовался для полного обхода; normal motion проверялся в начальной диагностике. Это покрытие конкретного веб-интерфейса и сценариев, а не утверждение об идентичном поведении на каждом физическом устройстве.

Существовавшие untracked каталоги и дополнительные artwork/assets других чатов сохранены. Commit, push и публикация не выполнялись.
