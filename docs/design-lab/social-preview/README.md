## Исходники

[Редактируемая композиция](source/layout.html) содержит проектный Unbounded, Arial, исходный знак тренажёра и прозрачный знак Yandex AI Studio. Сцена с вопросом и ответом создана через ImageGen; типографика и точные фирменные знаки собраны в HTML. В папке [source](source/) оставлены только материалы финальной композиции, [промпты](source/generation-prompts.md) и [происхождение файлов](source/provenance.json).

Для просмотра исходника при запущенном `npm run dev` откройте `/docs/design-lab/social-preview/source/layout.html`. Папка находится вне `public` и не входит в сборку сайта.
