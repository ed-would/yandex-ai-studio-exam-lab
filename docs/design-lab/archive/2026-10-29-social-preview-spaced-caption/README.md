# Архив social preview до объединения подписи

Сохранена версия social preview с разнесённой нижней подписью: название экзамена находилось слева, а строка «от Yandex AI Studio» справа. Архив создан перед новой композицией, где полный текст «Основы работы с ИИ» от Yandex AI Studio будет расположен одной строкой.

Файлы скопированы без изменения байтов. Манифест содержит исходные пути, архивные пути, размеры и SHA-256. Live-файлы проекта не изменялись в рамках архивирования.

В архиве сохранены текущий JPEG, краткое описание, raw PNG, промпт и provenance. Отдельных копий исходных файлов не создавалось за пределами этой папки.
