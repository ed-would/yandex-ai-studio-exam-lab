# Баннеры до текстовой подписи

Оригиналы README hero и social preview перенесены сюда 29 октября 2026 перед заменой логотипа и слов «на платформе» на строку «от Yandex AI Studio».

Файлы сохранены без изменения байтов. [Манифест](manifest.json) связывает исходные пути с архивными и содержит SHA-256 и размеры файлов. Прежний social preview хранится в одном экземпляре: два исходных пути с одинаковым содержимым ссылаются на один архивный JPEG. Также сохранена вся папка исходников с HTML-композицией, двумя изображениями, промптами и метаданными.

Структура внутри архива повторяет пути от корня проекта. Относительные ссылки в историческом HTML и README оставлены как были. Для восстановления композиции нужно вернуть файлы на пути `original_path` из манифеста; шрифты и фирменные знаки остаются в `public/` проекта.

Текущие баннеры находятся по прежним опубликованным путям. Новые исходные растры и промпты сохранены рядом с ними в `source/`.
