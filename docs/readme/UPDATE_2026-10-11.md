# README: очистка и новые композиции

Рабочая граница: пользовательский README, отдельный документ сопровождения, мобильный учебный цикл в двух темах и новый десктопный постер о форматах ответа. Презентации не создавались и не переделывались. Ссылки на них удалены из README. Публикация, аудит, Git-хуки, проверки коммитов, редактура банка, устройство исходников, демонстрационные макеты и производство графики вынесены из пользовательского пути; актуальное руководство находится в DEVELOPMENT.md, публикация в GITHUB_PUBLICATION.md, отчёты и происхождение графики остаются отдельно.

Новый второй постер заменяет повторение чисел hero на объяснение способов ответа. Прежний bank-map-v6 сохранён целиком. Четыре используемых hero-файла и два прежних WebP банка совпадают с исходными SHA-256. Новый постер подключён рядом с таблицей форматов, мобильный цикл использует отдельные source при ширине до 600 px.

Маршрут QUICK для ограниченных документальных и графических частей. Root отвечает за решение, производство, интеграцию и итоговые проверки. Делегированы перенос служебных разделов и чтение доказательств форматов. Прежняя история независимого review initial=1, recheck=1/max1 сохранена; дополнительных независимых waves и плановых gates нет. Код приложения, шрифты и runtime-палитра не изменялись. Общая проверка npm не запускалась повторно: новые проверки относятся к документации и статическим макетам, старый результат не заявляется результатом текущего рабочего дерева.
