# README: очистка и новые композиции

Рабочая граница: пользовательский README, отдельные документы сопровождения, мобильные версии инфографики и постер о форматах ответа. Ссылка на ранее созданную презентацию удалена из README; презентационные файлы не входят в читательский путь и в этой части не менялись. Публикация, аудит, Git-хуки, проверки коммитов, редактура банка, устройство исходников, демонстрационные макеты и производство графики вынесены из пользовательского пути. Руководство публикации находится в `GITHUB_PUBLICATION.md`, отчёты и происхождение графики — отдельно.

Новый второй постер заменяет повторение чисел hero на объяснение способов ответа. Прежний bank-map-v6 и версия постера v8 сохранены целиком. Четыре hero-файла и два прежних WebP банка совпадают с исходными SHA-256. README выбирает мобильные версии баннеров отдельно при ширине до 600 px.

Маршрут QUICK для ограниченных документальных и графических частей. Root отвечает за решение, производство, интеграцию и итоговые проверки. Делегированы перенос служебных разделов и чтение доказательств форматов. Прежняя история независимого review initial=1, recheck=1/max1 сохранена; дополнительных независимых waves и плановых gates нет. Код приложения, шрифты и runtime-палитра не изменялись. Общая проверка npm не запускалась повторно: новые проверки относятся к документации и статическим макетам, старый результат не заявляется результатом текущего рабочего дерева.

## Правильные пары и мобильный постер v9

По замечанию пользователя в обеих десктопных темах исправлены цвета правых терминалов и шнуров. Все три пары теперь соединяют одноцветные элементы. Остальная принятая десктопная композиция сохранена. Добавлены две мобильные композиции 1000 × 1800; README переключает их при ширине до 600 px. Версия v8 оставлена для истории.

Четыре итоговых JPG, исходники, промпты и доказательства находятся в `assets/readme/question-formats-v9`. Восемь сочетаний ширины и темы проверены локально; контраст финальных JPG от 4,780:1. Полная таблица проверок постера: [CHECKS.md](../../assets/readme/question-formats-v9/CHECKS.md). Прежние независимые волны не сброшены; новых reviews и плановых gates нет.
