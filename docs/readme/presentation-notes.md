# Презентация тренажёра

Комплект содержит восемь слайдов о самостоятельной подготовке, трёх тестах, шести доменах, разборе ответов, оценке, сохранениях и запуске проекта.

## Файлы

| Файл | Назначение |
| --- | --- |
| `presentation.pptx` | Редактируемые текст, таблица и схема в PowerPoint |
| `presentation.pdf` | Восемь страниц для просмотра и отправки |
| `presentation-preview.png` | Общий лист слайдов |
| `slides/slide-01.png` … `slides/slide-08.png` | Полноразмерные превью 1280 × 720 |
| `presentation-preview.html` | Статическая композиция для точной браузерной отрисовки |
| `presentation.mjs` | Исходник сборки PPTX через `@oai/artifact-tool` |

## Палитра и шрифты

Цвета соответствуют `DESIGN.md`: экспертный фиолетовый `#6841AB`, мягкая сирень, лайм базового, бирюза продвинутого и лиловый экспертного теста. Использованы оригинальные изображения `hero-ribbon-expanded-1152-optimized.webp`, три `level-*-512-optimized.webp` и собственный знак тренажёра `trainer-abstract-256-optimized.webp` из `public/`.

Заголовки и числовые акценты набраны в Unbounded, основной текст в Arial. Браузерный макет загружает оба локальных Unbounded WOFF2: кириллицу и латиницу с цифрами. Лицензия шрифта находится в `public/fonts/Unbounded-OFL.txt`; точные хеши файлов записаны в `assets/readme/source/manifest.json`.

В готовых PDF и PNG шрифт отрисован браузером. PPTX сохраняет названия Unbounded и Arial в редактируемых объектах, но не встраивает шрифты. Для точного отображения заголовков в PowerPoint нужен установленный Unbounded.

## Пересборка

Сначала `presentation.mjs` создаёт PPTX и проверяет пакет, геометрию и редактируемую таблицу. Промежуточные файлы и резервные PDF/PNG находятся в `node_modules/.cache/readme-presentation/`. Резервная отрисовка Artifact Tool использует Arial: его PDFKit-экспортёр не принимает WOFF2. Она не заменяет итоговые PDF и превью с Unbounded.

Пути к установленному инструментарию задаются через переменные окружения. Эти инструменты нужны для пересборки презентации; запуск самого тренажёра описан в README.

```bash
PRESENTATION_SKILL_DIR="/path/to/presentations/skill" \
RUNTIME_NODE_MODULES="/path/to/runtime/node_modules" \
PYTHON_EXECUTABLE="/path/to/runtime/python3" \
node docs/readme/presentation.mjs
```

Для окончательного PDF и PNG откройте `presentation-preview.html` через сервер `npm run dev` и `/pw`. Дождитесь `document.fonts.ready` и загрузки изображений. Снимите каждый элемент `.slide` размером 1280 × 720 и напечатайте HTML в PDF с фоном и размером страницы 1280 × 720 CSS px. Обновите общий лист превью. Все изображения и шрифты загружаются локально.

При замене рисунков измените пути и кадрирование в обоих исходниках. Изменения текста также внесите в JavaScript и HTML, чтобы редактируемый PPTX и браузерные версии совпадали.

## Источники и проверка

Факты взяты из `src/data/meta.js`, `docs/CONTENT_CONTRACT.md`, `docs/SOURCE_REVIEW.md`, `src/core/exam.js`, `src/core/storage.js` и `package.json`. Иллюстрация 47 из 60 даёт 78,3%; это арифметический пример. Цель 80% относится к тренировке и не объявляется официальным проходным баллом.

Проверены восемь слайдов 16:9, целостность PPTX, редактируемая таблица на четвёртом слайде, названия шрифтов и браузерная отрисовка с обоими локальными WOFF2. PDF содержит восемь страниц. PowerPoint и Google Slides отдельно не запускались. Полные границы проверки находятся в `REPORT.md`.
