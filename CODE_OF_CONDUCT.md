# Правила общения

Эти правила действуют в Issues, pull request и других пространствах проекта для всех участников, включая автора и сопровождающих.

## Ожидаемое поведение

- Общайтесь уважительно независимо от опыта, происхождения, возраста, пола, инвалидности, религии или других личных особенностей участника.
- Обсуждайте код, содержание и аргументы; давайте конкретную, конструктивную обратную связь.
- Допускайте добросовестные ошибки, принимайте исправления и помогайте новым участникам разобраться.
- Берегите приватность: используйте искусственные примеры вместо чужих личных данных.

Недопустимы угрозы, травля, оскорбления, дискриминация, нежелательные сексуальные комментарии, публикация чужих личных данных без согласия, спам и систематическое срывание обсуждений.

## Сообщить о нарушении

Чтобы сообщить о нарушении, воспользуйтесь [формой обращения в поддержку GitHub](https://github.com/contact/report-abuse). Укажите ссылки и краткое описание; не публикуйте чувствительные данные в открытой ветке обсуждения. Обращение рассматривает поддержка GitHub.

## Меры

Сопровождающий может отредактировать или удалить нарушающий правила контент, предупредить участника, временно ограничить взаимодействие или заблокировать участие. Мера зависит от тяжести нарушения и его повторяемости. Для обращений в поддержку GitHub гарантированных сроков ответа нет.
